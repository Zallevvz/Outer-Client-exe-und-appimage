OuterClient 6.4.1 — version picker bugfix

ROOT CAUSE
The 6.4.0 Minecraft version selector created its dropdown as a CTkFrame child
of self.content and positioned it with place()/lift(). The New Profile page is
inside CTkScrollableFrame/Canvas, so that overlay could end up behind the
scrollable page. The button callback ran, but visually nothing appeared.

FIX
- The selector no longer uses a self.content overlay.
- The New Profile page stores the exact version_wrap frame.
- The picker is created directly inside version_wrap.
- Opening uses grid(); closing uses grid_remove().
- The loader cards naturally move down while the version picker is open.
- The picker has a fixed 265 px scrolling area instead of becoming a giant
  screen-height dropdown.
- Search remains available.
- Search rendering is debounced.
- Selecting a version closes the picker and refreshes the Java/loader summary.
