OuterClient 6.3.3 — validation report

CHANGES
- Diagnostics profile selector rebuilt as a richer profile card with icon, name,
  Minecraft version and loader.
- Diagnostics selector opens a dedicated borderless profile popup.
- Linux/KDE custom titlebar is forced through managed-window no-border paths:
  _MOTIF_WM_HINTS via xprop and direct Xlib, plus a KWin scripting fallback.
- The launcher itself is explicitly kept non-topmost.
- Old scheduled 6.3.2 titlebar callbacks are redirected to the 6.3.3 implementation,
  so they cannot restore the native-only bar after startup.
- Taskbar / dock card is added to normal scroll flow below the existing Shortcut card.
- System Tools layout marker: Java row 2, updates row 3, shortcut row 4,
  spacer row 5, taskbar row 6.
