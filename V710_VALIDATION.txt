OuterClient 7.1.0 — Quality of Life Update

WINDOWS TASKBAR ROOT FIX
- Windows no longer uses overrideredirect(True) for the main window.
- The main HWND remains a normal managed top-level.
- Native caption is removed through Win32 WS_CAPTION instead.
- WS_EX_TOOLWINDOW is cleared.
- WS_EX_APPWINDOW is forced.
- Window owner is cleared with GWLP_HWNDPARENT=0.
- SetCurrentProcessExplicitAppUserModelID uses OuterClient.Launcher.7.1.0.
- Small and large native window icons are sent through WM_SETICON.
- Minimize uses normal iconify(), preserving the taskbar entry.
- The custom OuterClient titlebar remains active.
